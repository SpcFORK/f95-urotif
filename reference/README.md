# Preserved reference fixtures

The twelve files listed in `SHA256.json` are the original supplied prototype, samples, and usage document. Preserve their bytes; the test suite checks their hashes.

- `urotif/`: the supplied Oak implementation/wrappers.
- `smp/`: original Urotif samples, including intentionally retained failures and raw `.uru`/`.urb` inputs.
- `USAGE.original.md`: supplied usage text; it is not the current implementation guide.

Use [the project README](../README.md) for current commands. Reduced probes are in `../ablations/` and `../tests/oak-probes/`; original fixtures are not silently repaired.
